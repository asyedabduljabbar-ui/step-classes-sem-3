# Step Classes — Semester 3

## Week 1 Assignments

This repository holds the Week 1 live-coding session problems and the Week 1 assignment problems. The assignment solutions are grouped on the `feature-session-1` branch.

### Live-coding session problems

1. **Rock-Paper-Scissors Game** — five rounds, randomized computer moves, scoreboard, and win percentage.
2. **Palindrome Checker** — iterative, recursive, and array-reversal approaches.
3. **Team BMI Calculator** — BMI calculations, status classifications, and a formatted report.
4. **First Non-Repeating Character** — frequency counting and first unique character.
5. **Reverse Customer Name** — reverse the input while preserving the original.

### Week 1 assignment problems — `feature-session-1`

1. **Exam Hall Seat Duplication Checker** — finds repeated seat numbers using arrays and nested loops only; no collections.
2. **Typing Speed Test Accuracy Checker** — compares strings by character position, calculates accuracy, and reports the first mismatch.
3. **Traffic Signal Streak Analyzer** — finds the longest run of consecutive identical signal colors.
4. **Warehouse Inventory Balancer** — compares section totals and reports the highest quantity and its location.
5. **Movie Review Word Length Profiler** — counts short (1–4), medium (5–8), and long (9+) words.

## Requirements

- Java 8 or later
- A terminal or Java IDE

## Compile and run

From the repository root, compile all Java files:

```bash
javac *.java
```

Run any program by its class name. For example:

```bash
java ExamHallSeatDuplicationChecker
java TypingSpeedAccuracyChecker
java TrafficSignalStreakAnalyzer
java WarehouseInventoryBalancer
java MovieReviewWordLengthProfiler
```

The programs use beginner-friendly Java concepts including arrays, nested loops, string traversal, conditionals, counters, and methods. Inputs are read from the console.

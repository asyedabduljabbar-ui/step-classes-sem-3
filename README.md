# Step Classes — Semester 3

## Week 1: Java Programming Problems

This repository contains solutions to the five problems from the Semester 3, Week 1 live-coding assignment.

## Problems

1. **Rock-Paper-Scissors Game** — play five rounds, generate computer moves randomly, record each round, and report wins, losses, draws, and win percentage.
2. **Palindrome Checker (3 Approaches)** — check a string iteratively, recursively, and using array reversal.
3. **BMI Calculator for a Team** — calculate BMI and classify the result for each person in a team.
4. **First Non-Repeating Character** — return the first character that appears exactly once.
5. **Reverse Customer Name** — reverse a name without modifying the original string.

## Requirements

- Java 8 or later
- A terminal or Java IDE

## Compile and run

From the repository root, compile the Java files:

```bash
javac *.java
```

Run any problem independently:

```bash
java RockPaperScissors
java PalindromeChecker
java TeamBMICalculator
java FirstNonRepeatingCharacter
java ReverseCustomerName
```

Each program includes a `main` method and can be run independently. Inputs are read from the console where appropriate. The programs use core Java concepts such as loops, arrays, methods, recursion, conditionals, and string operations.
